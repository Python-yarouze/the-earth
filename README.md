# THE EARTH

石を積むように、太陽系を組む。

種類を選んで置き、START で手放して眺める。崩れたらやり直す。安定したらリンクで共有できる。

## 遊び方

```bash
npm install
npm test
npm run dev
```

- クリックで置く。ドラッグで水平、Shift で上下。速さは自動。
- START のあとは操作しない。見るだけ。
- 安定したら「共有」。URL を開くとその太陽系を眺められる。

## 公開

```bash
npm run build
```

`dist/` を GitHub Pages に出せます。ワークフローは `.github/workflows/pages.yml` です。リポジトリの Pages 設定で source を GitHub Actions にしてください。
