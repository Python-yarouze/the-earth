# THE EARTH

いまの地球も、軌道のバランスのうえにある。

石を積むように惑星を置き、START で手放して眺める。崩れたらやり直す。静かに続いたら、リンクで誰かに見せられる。

**プレイ:** https://python-yarouze.github.io/the-earth/

---

## なにをするゲーム？

太陽と地球がある宇宙に、惑星を置いて太陽系を組みます。  
START を押すとシミュレーションが始まり、惑星たちが重力で動き出します。軌道が続くか、いつか崩れるか——それを、ただ見守ります。

---

## 基本の流れ

1. **惑星を選んで置く**（配置モード）
2. **START** を押す（観察モードへ）
3. 軌道を眺める。崩れたら **やり直す**
4. 気に入ったら **共有** でリンクを渡す

---

## 操作

### 配置モード

| 操作 | 内容 |
|------|------|
| 左の惑星を選ぶ | 置きたい天体を選ぶ |
| 空を短くクリック | 惑星を置く |
| 惑星をドラッグ | 距離を変える |
| Shift ＋ ドラッグ | 高さを変える |
| 空をドラッグ | カメラを動かす |
| Delete | 選んだ惑星を消す |
| **太陽系** | 太陽系の並びを読み込む（解放後） |
| **ランダム** | ランダムな配置を試す（解放後） |
| **リセット** | いまの配置をやり直す |

**ヒント:** 月は地球の近くに置くと、衛星として回り始めます。

### 観察モード

| 操作 | 内容 |
|------|------|
| 惑星をクリック | その天体から周りを見る |
| **全体視点** | いつもの俯瞰に戻る |
| 速度ボタン | 時間の流れを変える |
| **分析** | 速度と重力の矢印を表示 |
| **奏でる** | 短い音を鳴らす |
| **ながす** | 奏でるを何度か聴いた先に解放 |
| **共有** | この太陽系のリンクを作る |
| **やり直す** | 配置モードに戻る |

地球が太陽を1周すると、ゲーム内で1年です。

---

## 楽しみ方

- **静かなバランスを、ただ眺める。** 崩れても宇宙は動き続けます。
- **図鑑** を開いて、少しずつ惑星の種類を増やしていく。
- **共有リンク** を開くと、誰かが組んだ太陽系をそのまま眺められる。
- 画面左下の **!** ボタンにも、ゲーム内のヒントがあります。

---

## 共有について

「共有」からリンクをコピーできます。  
URL を開いた人は、その太陽系を観察モードで眺められます。「自分でも組む」から、同じ並びを手がかりに組み直すこともできます。
